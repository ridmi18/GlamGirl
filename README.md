# GlamGirl - Fashion E-Commerce Website

GlamGirl is a fashion e-commerce website developed using PHP, MySQL, HTML, CSS, and JavaScript. It provides an online shopping experience with product browsing, shopping cart, checkout, and order management features.

## Features

- User registration and login
- Product browsing
- Shopping cart and checkout
- Order management
- Virtual fitting page
- Customer feedback and contact functionality
- Responsive web design

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ridmi18/GlamGirl.git
   ```
2. Install XAMPP or another PHP/MySQL development environment.
3. Place the project folder inside the web server directory.
4. Configure the database connection in `classes/DatabaseConnector.php`.
5. Start Apache and MySQL.
6. Open `http://localhost/GlamGirl/` in your browser.

**Note:** The required MySQL database schema must be configured separately.
